# mayoi-vsc2026-themes

VS Code **2026** color theme (Dark & Light) for [Mayoi](https://github.com/egoist/mayoi), mapped from VS Code's official `2026-dark.json` and `2026-light.json` themes with rounded bordered workbench panes (`paneRadius: 8`).

## Included Theme

- **VS Code 2026** (`vsc2026-themes.auto`) — automatically switches between 2026 Light and 2026 Dark with **View → Appearance** (System / Light / Dark)

## Install

Link locally for development:

```sh
mayoi plugin dev /path/to/mayoi-vsc2026-themes
```

Or install from Git:

```sh
mayoi plugin install <owner>/mayoi-vsc2026-themes
```

Then select **VS Code 2026** in Mayoi via **View → Theme → Color Theme…** or the Settings window.
